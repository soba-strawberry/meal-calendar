豚のしょうが焼き定食
🥩 豚うす切りしょうが焼き 🥒 きゅうりと玉ねぎのサラダ 🥣 新じゃが＆わかめの味噌汁

🛒 材料（4人分）

豚うす切り肉350g
しょうが1かけ
醤油大さじ3
みりん大さじ2
酒大さじ1
きゅうり2本
新玉ねぎ1/2個
新じゃが芋3個
わかめ（乾燥）5g
味噌大さじ2
だし汁600ml
サラダ油大さじ1

👨‍🍳 作り方

  1. 醤油・みりん・酒・すりおろしたしょうかを混ぜてタレを作る。豚肉を漬けて10分おく。
  2. きゅうりは薄切りにして塩でもみ、水けを絞る。新玉ねぎは薄切りにして水にさらす。ポン酢で和える。
  3. 新じゃがはよく洗い、半分に切る。わかめは水で戻す。だし汁でじゃがいもを柔らかくなるまで煮て、わかめを加え味噌を溶く。
  4. フライパンに油を熱し、豚肉を広げて中火で焼く。両面に焼き色がついたらタレを加えて絡め照りを出す。
豚肉は重ならないよう広げて焼くのが美味しく仕上げるコツ。タレは最後に加えると焦げにくい。
火曜日 6/16

🍗 鶏もものバター醤油炒め 🍆 なすの揚げびたし 🥣 にらと豆腐の味噌汁

🛒 材料（4人分）

鶏もも肉350g
とうもろこし2本
バター20g
醤油大さじ2
酒大さじ1
長なす3本
めんつゆ（2倍濃縮）大さじ3
水200ml
にら1束
豆腐1/2丁
味噌大さじ2
揚げ油適量

👨‍🍳 作り方

  1. とうもろこしは電子レンジで1本3分（ラップなし）加熱し、粗熱が取れたら包丁で実をそぎ落とす。
  2. なすは乱切りにして、170℃の油で2分素揚げし、油を切る。めんつゆを水で希釈したものに浸す。冷めると味がしみる。
  3. 鶏もも肉は一口大に切り、酒をふる。フライパンを中火にかけ皮目から焼き、こんがりしたら裏返す。とうもろこしを加えてバターを加え、醤油で味付け。
  4. だし汁に豆腐を加えて温め、にらを2cm長に切って加える。味噌を溶いて完成。
とうもろこしのレンジ加熱はラップなしがポイント！蒸気が逃げてシャキッとした食感になります。
水曜日 6/17
ヨークベニマル お魚の市
🐟 魚特売日
真あじの南蛮漬け定食
🐟 真あじの南蛮漬け 🥗 ほうれん草のごま和え 🥣 もずく＆新玉ねぎのスープ

🛒 材料（4人分）

生真あじ2尾
片栗粉大さじ3
新玉ねぎ1/2個
にんじん1/3本
酢大さじ4
砂糖大さじ2
醤油大さじ2
赤唐辛子（輪切り）少々
ほうれん草1束
すりごま大さじ2
味もずく3パック
揚げ油適量

👨‍🍳 作り方

  1. あじは3枚おろしにする（お店でお願いしてもOK）。塩こしょうし、片栗粉をまぶす。
  2. 南蛮ダレを作る：酢・砂糖・醤油・水50mlを合わせ電子レンジで1分加熱。薄切りにした玉ねぎ・にんじん・赤唐辛子を加える。
  3. あじを170℃の油で3〜4分揚げる。アツアツのうちに南蛮ダレに漬ける。30分以上おくと味がしみる。
  4. ほうれん草は塩茹でして冷水でさます。水けを絞り3cm幅に切り、醤油小さじ1とすりごまで和える。
  5. もずくは袋から出してお椀に盛り、熱いだし汁を注ぐだけ（味付き）。
南蛮漬けは前日に作っておくと翌日も美味しく食べられます！ほうれん草は少し多めに茹でて翌日の副菜にも使いまわしできます。
木曜日 6/18
ヨークベニマル 日配品の市
🍳 挽肉2割引
和風おろしハンバーグ
🍔 和風おろしハンバーグ 🌽 コーンと枝豆のバターソテー 🥣 新じゃが芋の豆腐汁

🛒 材料（4人分）

合いびき肉400g
玉ねぎ1/2個
卵1個
パン粉大さじ4
牛乳大さじ2
塩こしょう少々
大根5cm
ポン酢醤油大さじ4
みりん大さじ1
新じゃが芋3個
豆腐1/2丁
味噌大さじ2

👨‍🍳 作り方

  1. 玉ねぎをみじん切りにしてレンジ2分加熱し冷ます。ひき肉・卵・パン粉・牛乳・塩こしょうとともによくこねる。
  2. 4等分にして楕円形に整え、中央をへこませる。フライパンで中火2分焼き、裏返してフタをして弱火7分蒸し焼き。
  3. ハンバーグを取り出す。同じフライパンにポン酢・みりんを加えてひと煮立ちさせ、大根おろしを加えてソース完成。
  4. 新じゃがは小さく切ってレンジ3分加熱。だし汁に加えて豆腐と味噌を溶いて汁物を作る。
ハンバーグの中央をへこませると均一に火が通ります。大根おろしソースでさっぱりと、子どもも食べやすい和風仕立て。
金曜日 6/19
食材使いきりデー
♻️ 使いきり
塩鮭と夏野菜のホイル焼き
🐟 塩鮭と野菜のホイル焼き 🥗 ほうれん草の白和え 🥣 きゅうりと玉ねぎの冷やし汁

🛒 材料（4人分）

冷凍塩鮭（切り身）4切れ
長なす（残り）2本
新玉ねぎ（残り）1/2個
バター20g
酒大さじ2
ほうれん草（残り）1/2束
木綿豆腐1/2丁
白みそ大さじ1
砂糖小さじ1
きゅうり（残り）1本
冷水600ml
顆粒だし小さじ1

👨‍🍳 作り方

  1. 鮭は解凍しておく（前日冷蔵庫へ）。なすは輪切り、玉ねぎは薄切りにする。
  2. アルミホイルに野菜→鮭の順に乗せ、酒とバターを加えてしっかり包む。オーブントースターで15分焼く。
  3. 豆腐はキッチンペーパーで包んでレンジ1分加熱し水切り。すりつぶして白みそ・砂糖を混ぜる。塩茹でして冷やしたほうれん草を和える。
  4. 冷水に顆粒だしを溶かし、薄切りにしたきゅうりと玉ねぎを入れる。ポン酢を少々加えて冷やし汁完成。
ホイル焼きはオーブントースターにお任せなので、その間に副菜を準備できます。週の残り野菜をまとめて使い切れる便利メニュー！
⚠️ ヨークベニマルのセールは日替り（各日限り）のため、特売価格で買うには対象日に買い物が必要です。今週は3回に分けると全てのセール品を活用できます。
