月

ロースとんかつ定食

6/8（月） ・ 約25分

🥩 材料（4人分）

  • ロースとんかつ 99円均一1パック（4枚）
  • チンゲン菜 99円均一1袋（2株）
  • めかぶ 99円均一1袋（4パック）
  • キャベツ（千切り・付合せ）1/8玉
  • ごま油大さじ1
  • にんにく（チューブ可）小さじ1/2
  • オイスターソース大さじ1
  • しょうゆ小さじ1
  • 中濃ソース（とんかつ用）適量

📋 手順

  1. 1キャベツを細く千切りにして水にさらし、水気を切る（5分）
  2. 2チンゲン菜を洗い、葉と茎に分けて4cm幅に切る（3分）
  3. 3フライパンにごま油・にんにくを入れ中火で熱し、チンゲン菜の茎から炒める（3分）
  4. 4葉を加えてさっと炒め、オイスターソース・しょうゆで味付けする（2分）
  5. 5とんかつをオーブントースターに並べてアルミホイルをかぶせ、8〜10分温める（10分）
  6. 6器に盛り付け、めかぶを添える
揚げ済みとんかつはホイルをかぶせると外はサクサク、中はしっとりに仕上がります！

豚肉と新じゃがの煮物

6/9（火） ・ 約30分

🥩 材料（4人分）

  • 豚もも肉 3割引300g
  • 新じゃがいも 99円均一400g（小8〜10個）
  • にんじん 99円均一1本
  • 新玉ねぎ 99円均一2個
  • だし汁（または水＋顆粒だし）400ml
  • しょうゆ大さじ3
  • みりん大さじ3
  • 砂糖大さじ1
  • サラダ油大さじ1

📋 手順

  1. 1新じゃがは皮ごとよく洗い、大きいものは半分に切る（5分）
  2. 2にんじんは乱切り、新玉ねぎはくし切りにする（3分）
  3. 3豚肉を一口大（3cm程度）に切る（2分）
  4. 4鍋にサラダ油を熱し、豚肉を色が変わるまで炒める（3分）
  5. 5野菜を全て加えてさっと炒め、だし汁・しょうゆ・みりん・砂糖を加える（2分）
  6. 6沸騰したらアクを取り、落し蓋をして中火で15分煮る（15分）
新じゃがは皮が薄いので皮ごと調理OK！旨みが逃げず食感もホクホクです。

ウインナー焼きそば

6/10（水） ・ 約20分

🥩 材料（4人分）

  • 焼きそば麺 99円均一3袋
  • あらびきウインナー 99円均一1袋（約6本）
  • キャベツ（火曜の残り）1/4玉
  • 新玉ねぎ（火曜の残り）1個
  • かつおぶしめじ 99円均一1袋
  • ウスターソース大さじ4
  • しょうゆ小さじ1
  • 青のり・かつお節各適量

📋 手順

  1. 1キャベツをざく切り、玉ねぎを薄切り、ウインナーを斜め切りにする（5分）
  2. 2かつおぶしめじをさっと茹でてしょうゆで和え、おひたしを作る（5分）
  3. 3フライパンに油を熱し、ウインナー・野菜を炒める（5分）
  4. 4焼きそば麺を加えて水大さじ2を加えながらほぐし、ソース・しょうゆで味付けする（5分）
  5. 5皿に盛り付け、青のり・かつお節をかける
麺をほぐす前に少し水を加えると焦げずにほぐれやすくなります！

ぶりの照り焼き

6/11（木） ・ 約25分

🥩 材料（4人分）

  • ぶり切り身 特売598円4切れ
  • 新玉ねぎ（火曜の残り）1個
  • 豆腐（味噌汁用）1/2丁
  • しょうゆ大さじ2
  • みりん大さじ2
  • 酒大さじ2
  • 砂糖大さじ1
  • サラダ油大さじ1
  • ポン酢（サラダ用）大さじ2

📋 手順

  1. 1ぶりに塩少々を振って10分置き、水気をキッチンペーパーでふき取る（12分）
  2. 2しょうゆ・みりん・酒・砂糖を混ぜてたれを作っておく（2分）
  3. 3新玉ねぎを薄くスライスして水にさらし、水気を切ってポン酢で和える（5分）
  4. 4フライパンに油を熱し、ぶりを皮側から中火で3分、裏返して2分焼く（5分）
  5. 5余分な油をふき、たれを加えて照りが出るまで絡める（3分）
ぶりは塩を振って水分を出すことで臭みが取れ、たれがよく絡みます！

豚ロースの生姜焼き

6/12（金） ・ 約20分

🥩 材料（4人分）

  • 豚ロース薄切り 3割引350g
  • にんじん（火曜の残り）1/2本
  • キャベツ（月曜の残り）1/4玉
  • 卵（にんじんしりしり用）2個
  • しょうが（チューブ可）大さじ1
  • しょうゆ大さじ3
  • みりん大さじ2
  • 酒大さじ1
  • ごま油小さじ1

📋 手順

  1. 1にんじんを細切りにし、ごま油で炒め、溶き卵を加えて炒め合わせ、しょうゆで味付けして「しりしり」を作る（7分）
  2. 2キャベツを千切りにして水にさらす（3分）
  3. 3しょうゆ・みりん・酒・しょうがを混ぜ、豚肉に揉み込む（5分）
  4. 4フライパンを熱し、豚肉を広げながら両面焼く（5分）
  5. 5器に盛り付け、千切りキャベツ・にんじんしりしりを添える
にんじんしりしりは沖縄料理！彩りもよく子どもも喜ぶ副菜です。にんじんの甘みが際立ちます。
